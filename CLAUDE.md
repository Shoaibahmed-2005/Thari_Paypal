# Agent instructions

Read `docs/BUILD_PLAN.md` fully before doing anything. It is the single source of truth for what to build, how, the brand kit, and which steps need the human (MANUAL items M1–M12).

- Resume from `docs/PROGRESS.md` (create it if missing) and update it after every task.
- Build phase by phase (section 15); don't start a phase before the previous one's acceptance tests pass.
- At a MANUAL item, stop and ask the human for exactly what it lists.
- Never commit secrets. Never change the brand tokens.
